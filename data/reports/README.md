# Source reports

Place the 15 downloaded sustainability-report PDFs in this directory. PDF files are intentionally ignored by Git because they are large third-party documents.

Download: [Sustainable-VEG dataset materials](https://drive.google.com/drive/folders/1uf5v9DCFWm5wEiVOgcaqFbxmdVwmAXjc?usp=sharing)

To check filenames after download, run from the repository root:

```bash
python scripts/validate_dataset.py --check-reports
```
